Spectral Utilities (`specutils`) source lives at
https://github.com/eehunter/Spectral-Utilities (single branch `master`).

The `contact.sources` field inside the shipped `specutils-1.3.1.jar`'s
`fabric.mod.json` claims `https://github.com/DaFuqs/specutils`, which 404s
(private, renamed, or deleted). Do not trust that field. The working URL was
recovered from the CurseForge project page's Source link. Author is
`jghunter48` / "Ned Hunter" (hence the `eehunter` GitHub owner).
